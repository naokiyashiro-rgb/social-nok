# Week 1 投稿テーマ計画（9月30日 - 10月6日）

## 戦略

Week 1 は、プロフィール更新直後のため、プロフィール訪問数が最も増える期間です。この時期に、各テーマの代表的な投稿を優先的にして、「この人のアカウントは何をしているのか」を明確に理解させることを目指します。

## テーマ別の投稿目標

各テーマから最低1投稿、合計で7日間で6-8投稿を目安とします。

| テーマ | 投稿数目標 | 形式 | 目的 |
|-------|---------|------|-----|
| 🤖 AI活用 | 1-2 | 実験・試行錯誤 | AI関心層への訴求 |
| 📊 マーケティング | 1 | 事例・結果報告 | マーケッター層への訴求 |
| 👔 マネジメント | 1 | 工夫・学び | 管理職層への訴求 |
| 🧠 メンタル・働き方 | 1 | 試行錯誤・経験 | 働き方関心層への訴求 |
| 😴 睡眠・コンディション | 1 | 実験結果 | ウェルネス関心層への訴求 |
| 💪 筋トレ・フィットネス | 1 | 進捗・工夫 | フィットネス関心層への訴求 |

## 日程別投稿計画

### 9月30日（月）- プロフィール更新直後

**朝の投稿1（プロフィール紹介兼ね）**:
- **テーマ**: 総合的な自己紹介
- **形式**: スレッド（複数の連続投稿）
- **内容例**: 「フリーで働きながら、こんなことを試してます」という導入
- **目的**: プロフィール訪問層に対して、「この人は何を発信しているのか」を説明

**例文**:
```
フリーで働きながら、最近こんなことを試してます。

📌 AI：毎日のタスク整理をClaudeでどう効率化するか
📌 マーケ：新しいコンテンツフォーマットの反応を計測中
📌 マネジメント：リモートチームのモチベーション管理
📌 睡眠：睡眠時間と仕事の質の関係を記録
📌 筋トレ：年内に体脂肪率を〇%に…（ここからが試行錯誤）

毎日、失敗も含めてそのまま発信します🧪
```

**昼または夜の投稿2**:
- **テーマ**: 実験系（失敗or途中経過）
- **形式**: テキスト + リプライ欄を活用
- **内容例**: 「〇〇を試したけどうまくいかなかった」系
- **目的**: 「成功談だけじゃなく失敗も発信する」ことを実装で示す

### 10月1日（火）- AI活用テーマ

**投稿1**:
- **テーマ**: 🤖 AI活用（実務的）
- **形式**: テキスト + 画像（スクリーンショット等）
- **内容例**: 「Claudeを使って〇〇したら△△%の時短になった」
- **目的**: AI関心層の発見・フォロー
- **ポイント**: 数値があると説得力が高まる

**例文のトーン**:
```
Claudeを使って業務を自動化してみた。

【Before】毎日30分かかっていた〇〇という作業
【After】Claudeに〇〇のプロンプトを投げたら2分に短縮

…ただし、品質チェックには5分かかるので、
正味の時短は17分くらい。

でも毎日これが積み重なると、月5時間の時短。
その5時間を別の仕事に回せるので効果大。
```

### 10月2日（水）- 試行錯誤・失敗テーマ

**投稿1**:
- **テーマ**: 失敗・試行錯誤（複数テーマ可）
- **形式**: テキスト
- **内容例**: 「〇〇だと思って試したけど、実は△△だった」
- **目的**: 「この人は失敗も発信する」を示す
- **ポイント**: 失敗から学んだことを明確に

**例文のトーン**:
```
マネジメント失敗：

チームの生産性を上げたくて、
毎日15時に全員の進捗確認ミーティングを入れた。

が、これが大失敗。

理由：
・各自の集中タイムを妨害
・実際に同期が必要な日は週1でいい
・その他の日は非同期で十分

今週から週1の同期ミーティングに変更した。
生産性が戻った。

同期・非同期の使い分けが重要。
```

### 10月3日（木）- マーケティング・データテーマ

**投稿1**:
- **テーマ**: 📊 マーケティング（データ or 事例）
- **形式**: テキスト + グラフなど
- **内容例**: 「〇〇という施策をやったら、△△という結果になった」
- **目的**: マーケッター層の発見・フォロー
- **ポイント**: 数値・データがあると信頼性が高まる

**例文のトーン**:
```
最近始めた【テーマA】というコンテンツフォーマット。

3週間の反応を集計してみた：

従来フォーマット：平均リーチ 200 / いいね 15
新フォーマット：平均リーチ 450 / いいね 35

リーチが2倍以上。

ただし作成時間が1.5倍かかってるので、
効率性の検証はこれから。

来月も続ける予定。
```

### 10月4日（金）- ウェルネス系テーマ

**投稿1**:
- **テーマ**: 😴 睡眠 or 💪 筋トレ
- **形式**: テキスト + 数値
- **内容例**: 「睡眠時間を〇〇に変えたら、仕事の質が△△」
- **目的**: ウェルネス関心層の発見
- **ポイント**: 睡眠・フィットネスは成果が見えやすいテーマ

**例文のトーン**:
```
睡眠実験：

3ヶ月、夜11時就寝 → 朝6時起床を実験中。

【体感】
・朝の集中力が確実に上がった
・昼間の眠気が減った
・イライラが減った気がする

【課題】
・夜11時就寝はリモートワークでも難しい（休日は対応）
・定期的に21時に寝ると効果がさらに高い

完全にルーティン化するまではまだ途上。
```

### 10月5日（土）- 複数テーマの交流型

**投稿1**:
- **テーマ**: 複数テーマの統合、or 他人の投稿への返信・引用投稿
- **形式**: 引用投稿 or スレッド
- **内容例**: 「〇〇という人の投稿を読んで、自分も同じテーマで試してみた結果…」
- **目的**: 交流を深める、複数テーマの関連性を示す
- **ポイント**: 他人の投稿を引用しながら、自分の経験を追加

**例文のトーン**:
```
@[アカウント]の投稿を読んで、私も同じことを試してました。

睡眠改善 → 仕事の生産性向上 → マネジメントの質向上

という流れは本当に感じます。

特に、疲れた状態でのマネジメント判断は、
後で後悔することが多いので…

ウェルネスとマネジメントの関連性は意外と深い。
```

## 投稿内容の工夫

### 共通の形式

すべての投稿に、以下の要素を含めることを目指します：

1. **ビフォー・アフター or 問題・解決**
   ```
   問題：〇〇が課題だった
   施策：△△を試した
   結果：□□に改善した
   ```

2. **失敗から学んだこと**
   ```
   最初は〇〇だと思った
   が、実際は△△だった
   だから〇〇に改善した
   ```

3. **数値・具体性**
   ```
   ❌「効率が上がった」
   ✅「〇〇時間 → △△時間に短縮（タイムシートで確認）」
   ```

4. **途上感**
   ```
   「完全にルーティン化するまではまだ途上」
   「来月も継続して検証予定」
   など、「試行錯誤中」を表現
   ```

### 投稿のトーン例

✅ **親しみやすく途上感がある**:
```
最近Claudeを使って業務を自動化してみた。
うまくいった部分も、失敗した部分もある。

【成功】データ整理が30分 → 5分に
【失敗】品質チェックで逆に時間がかかるように…

現在、プロンプトを調整中。
```

❌ **専門家っぽく上から教えるスタイル**:
```
これからの時代、AIを使った自動化は必須です。
以下のステップで実装してください：
1. まずはプロンプトの設計から…
```

## 注意点

1. **品質重視**: 無理に毎日投稿する必要はなし。質の高い投稿を優先
2. **実体験必須**: 実際に試していないテーマの投稿は避ける
3. **失敗も含める**: 成功談だけでなく、失敗や途中経過も発信する
4. **他の投稿とのバランス**: 予約投稿の継続と、ここでの新規投稿のバランスを取る
