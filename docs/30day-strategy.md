# 30日間 X（Twitter）発信強化施策

**期間**: 2026年9月28日 - 2026年10月28日  
**主要目標**: 「この人の投稿また見たい」と思われるアカウント構築

## 発信者の軸

**フリーで働きながら、仕事も自分もアップデートしている人**

自分の仕事と人生のパフォーマンスを上げるために、実際に試したことをそのまま発信します。成功談だけでなく、失敗や試行錯誤の途中経過もコンテンツとして扱います。

トーン：親しみやすく「自分も試している途中」という雰囲気で、専門家っぽく上から教えるようなスタイルではありません。

## 発信テーマ

- 🤖 **AI** - AI / 自分専用AI / AIエージェント / 自動化
- 📊 **ビジネス** - マーケティング / 事業運営
- 👔 **マネジメント** - 管理職 / チームビルディング
- 🧠 **ウェルネス** - メンタル / 働き方 / 睡眠 / コンディション / 筋トレ / フィットネス

**テーマの共通軸**: 仕事と自分のパフォーマンスを上げるために、実際に試したことを発信する

## 基本方針

### 実施する内容 ✅
- 既存の予約投稿を維持し、テーマと形式を記録
- 毎日、実際に交流したいアカウントと投稿候補を整理
- 自分の実体験を交えた返信案と引用投稿案を用意
- プロフィール文と固定投稿を、発信者の軸に合わせて改善
- 投稿結果を分析し、毎週改善施策を報告
- 本当に関心のある、継続的に交流したいアカウント優先
- 成功談と同じくらい失敗や試行錯誤も発信

### 実施しない内容 ❌
- 自動いいね・自動フォロー・他人への自動返信
- トレンドを狙った自動投稿
- 大量フォロー戦略、フォロー返し獲得戦略
- AI専門アカウント化

## 主要KPI（優先度順）

1. **インプレッション数** - コンテンツ認知度
2. **プロフィール訪問数** - アカウント発見度
3. **プロフィール訪問 → フォロー率** - 信頼度・魅力度
4. **投稿別の新規フォロワー獲得** - 投稿品質
5. **返信・引用経由のプロフィール訪問** - 交流の質
6. **外部流入（note等）** - 他プラットフォーム連携効果

※ フォロー返し率は主要KPIから外す（質重視）

## 運用プロセス

### 1. 準備フェーズ（9月28-29日）

- [ ] 発信者の軸を確認・理解
- [ ] 新プロフィール案から最適なものを選択
- [ ] 固定投稿案から最適なものを選択
- [ ] 最初の7日間の投稿テーマを確認
- [ ] 交流候補を探すための検索キーワードを把握
- [ ] 交流相手の選定基準を理解

### 2. 実行フェーズ（9月30日 - 10月27日）

**毎日のアクション**:
1. X（Twitter）のタイムラインを確認（20分）
2. 本当に関心のあるアカウント1-3件を発見・フォロー
3. 返信案と引用投稿案を準備（20分）
4. 実際に投稿・交流を実行（手動、20分）

**定期的なアクション**:
- 週次：投稿結果の分析と改善施策の検討
- 週次：新しい交流候補の発掘

### 3. 測定・改善フェーズ

**毎週測定・記録**:
- インプレッション数
- プロフィール訪問数
- プロフィール訪問 → フォロー率
- 投稿別の新規フォロワー獲得
- 返信・引用経由のプロフィール訪問
- 外部流入

**毎週実施**:
- 伸びたテーマ・投稿形式の分析
- フォロワーの属性分析（AI、マーケティング、フリーランス等）
- 次週の投稿計画の最適化

## 交流戦略

### 交流の目的

「この人の投稿また見たい」と思われる状態を作る。そのために、本当に関心のある相手との継続的な交流を優先します。

### 交流候補の選定基準

各領域から、本当に発信テーマが近く、継続的に交流したいと思える相手を選定：

1. **AI活用** - 実務的なAI活用を発信している人
2. **マーケター** - マーケティング知見や施策結果を共有している人
3. **フリーランス** - フリーで働く上での工夫や知見を発信している人
4. **経営 / マネジメント** - 経営やマネジメントの実験・学びを発信している人
5. **睡眠 / 生産性** - 睡眠やコンディション管理の実験を発信している人
6. **フィットネス** - 筋トレやフィットネスの実験・知見を発信している人

### 量より質

- 初期段階で50-70件の大量リストアップは目指さない
- 1人ひとり投稿内容を読んで、本当に関心のある相手を選定
- 継続的に交流できる相手を優先（短期的なフォロー返しではなく）

## 次のステップ

1. 新プロフィール案（3案）を確認・選択
2. 固定投稿案（3案）を確認・選択
3. 最初の7日間の投稿テーマを確認
4. 交流候補を探すための検索キーワードを把握
5. 初週のKPI表を確認
6. プロフィール・固定投稿を更新（9月30日）
7. 実際の交流・投稿を開始（9月30日から）
