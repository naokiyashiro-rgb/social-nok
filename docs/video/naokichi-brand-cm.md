# たぬきマーケター・ナオ吉 ブランディングCM（縦型ショート）

**尺**: 36秒 ／ **比率**: 9:16（1080×1920）／ **想定**: TikTok・Instagram Reels・YouTube Shorts
**目的**: 商品宣伝ではなく「ナオ吉」というキャラクターを覚えてもらう
**狙う感情の流れ**: 「なんだこのたぬき？」→「ちょっと面白い」→「あれ、意外とちゃんとしてる」→「もう少し見てみたい」
**最重要**: 普段は抜けている ⇔ 仕事になると急に鋭い、のギャップ

---

## 0. 制作方針（先に決めておくこと）

### ビジュアルの基本方針
- **背景と人間**: 少しシネマティックな実写風のオフィス（明るすぎず、色は抑えめ）
- **ナオ吉**: 添付画像そのままのイラスト調。実写の中に1匹だけイラストのたぬきがいる状態にして、**「なんか変」なシュールさ**を出す
- **PC画面**: 添付バナーのような「暗い画面にシアン系の光」のUIトーン。ただし **「NOK」の文字やサービス名は一切出さない**

### キャラクター統一のための制作手順（推奨）
動画生成AIだけで全カットを作ると、顔・葉っぱ・ヘッドホンが途中で変わりやすいです。以下の順番で作ると崩れにくくなります。

1. 添付画像を**基準画像**に固定する（ファイル名例: `naokichi_ref.webp`）
2. 表情違いのキーフレーム画像を先に作る（通常／真顔／ドヤ／「あ。」／正面）。**必ず基準画像を参照画像として渡す**
3. 各キーフレームを image-to-video で2〜4秒ずつ動かす
4. ナオ吉は単色背景で生成して、編集時に背景と合成するのが一番安定する
5. 仕上げ段階で、全カットのナオ吉を基準画像と並べてチェックする（下のチェックリストを使う）

### キャラクター固定チェックリスト（全カット共通）
- [ ] 顔: 丸顔、目の周りが焦げ茶のマスク模様、クリーム色の口元、茶色の小さい鼻
- [ ] 目: 白目の大きい丸目。黒目は小さく、**左右で少しずれている**（これが「抜け感」の元なので消さない）
- [ ] 頭の葉っぱ: 黄緑の葉1枚、頭頂部のやや左、茎が右上にカール
- [ ] ヘッドホン: 黒、首にかけている。イヤーカップにシアンの発光リングと葉っぱマーク
- [ ] 白いパーカー: オフホワイト、黒い紐、紐先はオレンジと黒、前にカンガルーポケット
- [ ] 体型: 2.5頭身くらい、ずんぐり、短い手足、しっぽは太くて縞模様
- [ ] 線画: 茶色系の太めの輪郭線、ふわっとした毛並み

## 2. カット割り詳細

画面構成の凡例: **上段**（0〜25%）＝テロップの安全域 ／ **中段**（25〜70%）＝主役 ／ **下段**（70〜100%）＝各SNSのUIで隠れやすいので、重要な情報は置かない

---

### CUT 1｜0:00-0:03｜重たい会議（3カットを1秒ずつ）

- **映像**: 夕方の会議室。ブラインド越しの斜めの光。スーツ姿の人間3人。ホワイトボードに下がり調子の折れ線グラフ。机にノートPCと紙の資料。
  - 1a（0:00-0:01）人Aの横顔の寄り「CPAが悪化しています」
  - 1b（0:01-0:02）人Bの手元（資料をめくる）「CVRも落ちています」
  - 1c（0:02-0:03）会議室の引き、全員うつむき「クリエイティブ、増やしますか？」
- **カメラ**: 1aはゆっくりのドリーイン、1bは真上からの俯瞰、1cは固定の引き
- **テロップ**: 各セリフを字幕として上段に（白文字、細いゴシック体）
- **BGM/SE**: 低いシンセのドローン音（重たい空気）。空調の音と時計の秒針
- **9:16構成**: 1cは画面の下3分の1を空けておく（次のカットでたぬきが出てくる場所）
- **ポイント**: 冒頭1秒で「よくある会社の会議」だと分からせる。字幕は必須（無音で見る人が多いため）

### CUT 2｜0:03-0:05｜たぬき登場

- **映像**: CUT 1cと同じ構図のまま、画面右下の机の端から**頭の葉っぱ → 目 → 顔**の順にゆっくり出てくる。表情はいつもの抜けた顔（黒目が左右にずれている）。
- **セリフ**: ナオ吉「……それ、広告の問題？」（ボソッと。やる気がなさそうに）
- **カメラ**: 固定。動かさないことでシュールさが出る
- **表情・動き**: まばたき1回。口はほとんど動かさない
- **SE**: 出てくる瞬間に「ぽよっ」という小さな音（控えめに）
- **BGM**: セリフの直前でドローン音がフッと切れる
- **テロップ**: セリフ字幕を中段右寄せ。「……」を入れて間を見せる

### CUT 3｜0:05-0:06｜「え？」

- **映像**: 人間3人が同時にたぬきの方を振り向く。一斉に。
- **カメラ**: たぬき越しの肩ナメで人間3人を撮る（たぬきの後頭部と葉っぱを手前にぼかして入れる）
- **セリフ**: 全員「え？」
- **SE**: 無音 → 「え？」の直後にレコードのスクラッチ音（ごく短く）
- **トランジション**: ここまではカット割りを速く。「え？」で0.3秒止める（フリーズフレーム）

### CUT 4｜0:06-0:08｜椅子によじ登る

- **映像**: たぬきが会議室の椅子に短い手足でよじ登る。一瞬ずり落ちかける。登りきってノートPCを開く。
- **カメラ**: 横からの固定ミディアム
- **表情**: 必死だけど無表情
- **SE**: 椅子のきしむ音、PCを開く「カチャ」
- **BGM**: ここで**本編のBGMが始まる**（ローファイ・ヒップホップのビート＋少しおどけた音色のプラック）
- **テロップ（上段・小さく）**: 「？？？」 or なし（なしを推奨）

### CUT 5｜0:08-0:13｜分析モード突入（最大のギャップ）

- **映像**: PC画面にモニターの光が当たり、**たぬきの表情が変わる**。黒目が中央に揃って、目がすっと細くなる。顔にシアン色のモニター光。
  - 画面がBGMの拍に合わせてパンッパンッと切り替わる（1枚0.6〜0.8秒）: `売上` → `CRM` → `顧客データ` → `営業` → `LP` → `ユーザーの声`
  - 各画面は暗い背景にシアン・紫のUI（グラフ、表、口コミのカードなど）。**文字は読めなくていい。ラベルだけ読めればOK**
- **セリフ**: ナオ吉「広告だけ見ても、分かんなくない？」（声のトーンが一段低くなる）
- **カメラ**: 画面の切り替わりに合わせて、たぬきの顔にじわっとドリーイン
- **9:16構成**: 上半分にPC画面のUI、下半分にたぬきの顔（画面の光で照らされている）
- **SE**: 画面が切り替わるたびに小さな「チッ」というUI音
- **テロップ**: 各画面のラベルを上段に左から右へタイプ表示（`売上` `CRM` …）
- **ポイント**: **この動画で一番大事なカット**。目が変わった瞬間に「あれ？」と思わせる

### CUT 6｜0:13-0:18｜三段の言い切り

- **映像**: 3つのカットをマッチカット（同じ構図のまま中身だけ切り替える）
  - 6a「集客して。」— 背景に人が入ってくる動線のアイコン（矢印）
  - 6b「売って。」— レジ／カートのアイコン
  - 6c「また来てもらう。」— ループ矢印のアイコン
- **カメラ**: たぬきは中央で固定。1カットごとに少しずつ寄る（ズーム3段）
- **表情**: 真顔。1言ごとに小さくうなずく
- **BGM**: 3拍のキック音に合わせて1言ずつ（ここはBGMとセリフを完全に同期させる）
- **テロップ**: 太字で中段に大きく1語ずつ。3つ目を表示したあと、3つを横に並べて矢印でつなぐ（`集客 → 販売 → リピート`）

### CUT 7｜0:18-0:20｜本質の一言

- **映像**: たぬきの顔の寄り。モニター光。少しだけ首をかしげる
- **セリフ**: ナオ吉「そこまでつながって、マーケじゃないの？」
- **カメラ**: 固定の寄り、ゆっくりラックフォーカス（背景の人間たちにピントが移り、ぽかんとしている顔が映る）
- **BGM**: 一瞬、音数を減らす
- **テロップ**: セリフ字幕のみ

### CUT 8｜0:20-0:26｜自分専用AIとの仕事

- **映像**: 会議室の外、自分の作業デスク（暗めの部屋、モニター1〜2枚、観葉植物、コーヒーカップ）。たぬきがヘッドホンを片耳だけ当てて、PCに話しかける。
  - 8a（0:20-0:22）ナオ吉「今日の数字、昨日と違うところだけ教えて。」
  - 8b（0:22-0:23.5）AI「大きな変化は3つあります。」— 画面に3枚のカードがスッと並ぶ（`① 新規流入 ↓` `② LP離脱 ↑` `③ リピート率 →`）
  - 8c（0:23.5-0:25）ナオ吉「じゃ、一番怪しいところ深掘って。」— 肉球で②のカードをタップ
  - 8d（0:25-0:26）AI「了解。」— ②のカードが展開して、細かいグラフが出てくる
- **AIの表現**: キャラクターや顔は出さない。**画面の端の小さなシアンの波形と文字だけ**。声は落ち着いた中性的な合成音声。サービス名・ロゴは出さない
- **カメラ**: たぬきの肩越しに画面を撮る → 8cだけ肉球の寄り
- **SE**: カードが並ぶ時に柔らかい「ポン、ポン、ポン」
- **テロップ**: AIのセリフは画面内のUIテキストとして表示（字幕とはフォントを変える、等幅フォント）
- **ポイント**: 「AIすごい」ではなく、**「このたぬき、普通にAIを部下みたいに使ってる」**と見えるように。会話は短く、慣れた感じで

### CUT 9｜0:26-0:30｜抜ける

- **映像**:
  - 9a（0:26-0:27）ドヤ顔で椅子にもたれて腕を組む（決めポーズ）
  - 9b（0:27-0:27.5）その時に肘が机のおせんべいの袋に当たって、床に落ちる
  - 9c（0:27.5-0:29.5）たぬき「あ。」— 黒目がまた左右にずれる（いつもの抜けた顔に戻る）。**2秒間の無音・固定**
  - 9d（0:29.5-0:30）何もなかったように、スッと前を向いてキーボードを打ち始める
- **カメラ**: 9a〜9cは固定の引き（落ちる袋もフレームに入れる）。**カットを割らない**のがポイント
- **BGM**: 袋が落ちた瞬間に**BGMが完全に止まる**。9dでBGMが戻る
- **SE**: 「カサッ」（袋が落ちる音）だけ。大げさな効果音は入れない
- **テロップ**: なし（何も言わない方が面白い）
- **ポイント**: ギャグにしすぎない。**表情と間だけ**で見せる

### CUT 10｜0:30-0:36｜ラスト

- **映像**: 無地の背景（オフホワイト〜薄いベージュ）にたぬきが正面を向いて立っている。添付画像とほぼ同じポーズ・構図。
  - 10a（0:30-0:32）テロップ「たぬきマーケター ナオ吉」
  - 10b（0:32-0:34.5）テロップ「マーケティングを、もうちょっと面白く。」
  - 10c（0:34.5-0:35.5）ナオ吉（小声）「たぶん。」— 目線だけ少し横にそらす
  - 10d（0:35.5-0:36）暗転
- **カメラ**: 正面固定、ほんの少しだけドリーイン
- **9:16構成**: たぬきは中段、テロップは上段（名前）と下段寄りの中段（コピー）。アカウント名は最後の0.5秒に小さく
- **BGM**: 10bでビートが抜けてプラックの音だけ残る → 「たぶん。」の後に1音で終わる
- **SE**: 暗転の直前に小さく「ぽよっ」（CUT 2と同じ音で、始まりと終わりをそろえる）
- **テロップの書体**: 名前は太めの丸ゴシック、コピーは細いゴシック。「たぶん。」は字幕ではなく**声だけ**、または極小の手書き風フォント

## 3. ラストコピーの比較

| | A:「マーケティングを、もうちょっと面白く。」＋「たぶん。」 | B:「見た目はたぬき。中身はマーケター。」 |
|---|---|---|
| **伝わること** | 姿勢・スタンス（上から教えない、一緒に試す人） | ギャップ（キャラの構造） |
| **キャラとの相性** | 「たぶん。」で抜け感が最後に戻り、ナオ吉らしさが一番出る | 分かりやすいが、自己紹介っぽい |
| **覚えやすさ** | 中（少し長い） | 高（対句なので口に出しやすい） |
| **次の投稿を見たくなるか** | 高（「この人は何をするんだろう」という余白がある） | 中（本編で見せたことの答え合わせで終わる） |
| **シリーズ化** | 他の動画でも使い回せる | 初回の自己紹介動画向き |

**推奨**: メインはA。Bは**冒頭のフック**（CUT 4の上段テロップ）か、プロフィール・固定ポストのコピーとして使い分ける。
両方使いたい場合は、Bを0:06に小さく出して、Aをラストに置く構成も可能（ただし文字が多くなるので、最初はAだけで試すのがおすすめ）。

## 8. 別方向性（短く）

### もっとコミカル版 —「ナオ吉、会議を乗っ取る」
- 会議室に入ってくる時点でドアに頭の葉っぱがはさまる
- 分析シーンは同じように鋭く見せるが、画面の切り替えのたびに**人間たちの表情がだんだん尊敬のまなざしに変わっていく**リアクションを挟む
- AIとのやり取りで、AIが「大きな変化は3つあります」→ナオ吉「2つでいい」→AI「……了解」のような小さいボケを入れる
- ラストは「見た目はたぬき。中身はマーケター。」→ナオ吉「……おなかすいた」
- **リスク**: 笑いが増えるほど「鋭い」の印象が薄れる。お菓子のくだりは1回に限定したい

### もっとスタイリッシュ版 —「夜のナオ吉」
- 会議室は使わず、夜の作業部屋だけで完結（添付バナーのような暗いシアン・紫の世界観を全面に）
- セリフを減らして、テロップとビートで見せる（「広告だけ見ても、分からない。」「集客。販売。リピート。」をタイポグラフィのアニメーションで）
- 抜けるシーンはお菓子ではなく、**最後にヘッドホンを頭につけようとして葉っぱに引っかかる**1カットだけ
- ラストは「見た目はたぬき。中身はマーケター。」が合う（スタイリッシュな雰囲気とギャップのある対句がかっこよくまとまる）
- **リスク**: かっこよく作れるが、「この人に話しかけてみたい」という親しみやすさは下がる

## 9. 制作時の注意

- 「NOK」や特定のAIサービス名・ロゴは一切映さない（PC画面・ステッカー・マグカップも含めて）
- 会議室の人物は実在の人物に似せない（生成時に有名人の名前を入れない）
- 投稿の実行はアカウント運用ルールと同じく、人間の承認後に手動で行う
