# 交流候補の探し方＆選定基準

## 概要

フォロー返し率を目的にした大量フォロー戦略ではなく、本当に関心のある相手との継続的な交流を優先します。毎日、検索キーワードを使って、発信テーマが近い相手を1-3人見つけることを目指します。

## 交流相手の選定基準

### ✅ フォローするべき相手

以下の条件を満たす人を、優先的にフォロー・交流の対象にしてください：

#### 1. 投稿内容が「実験」「試行錯誤」を含む

**OK**:
```
「Aという方法を試したが失敗した」
「Bという施策を実装中、現在の進捗は…」
「3ヶ月試した結果、この方法が最適だった」
```

**NG（スキップ推奨）**:
```
「〇〇すべき」「これが正解」という一方的な主張
「成功した」という話だけで、失敗や途上感がない
```

#### 2. 複数のテーマを発信している

**OK**:
```
マーケティングと睡眠を発信している人
AIと筋トレを発信している人
```

**NG（スキップ推奨）**:
```
AI専門だけの人（相互交流が薄い可能性）
```

#### 3. 発信者のトーンが親しみやすい

**OK**:
```
「実装中で、まだ改善途上です」
「失敗も多いですが、学びになってます」
```

**NG（スキップ推奨）**:
```
「これが鉄則です」「絶対にすべき」という上から目線
```

#### 4. フォロワー数が適正範囲

**推奨**: 1,000〜500,000フォロワー
- 1,000以下：アカウントとして発展途上
- 500,000以上：大規模アカウント（交流の時間効率が悪い）

#### 5. 定期的に投稿している

**推奨**: 週2回以上の投稿頻度

**理由**: 一時的なアカウント、休止中のアカウントは避ける

#### 6. リプライに返信している

**OK**:
```
他人のリプライに返信している
自分の投稿にコメントが付いている
```

**理由**: 交流を重視しているアカウントの可能性が高い

---

### ❌ フォローを避けるべき相手

#### 1. 自動投稿・ボット疑い

**避ける理由**:
```
同じリンクばかり投稿
時間きっかり同じに投稿
リプライへの返信がない
```

#### 2. スパム・営業色が強い

**避ける理由**:
```
「無料でXXX」「期間限定」の繰り返し
自分の商品・サービスの宣伝ばかり
リプライで営業DM
```

#### 3. 炎上・議論喧嘩が多い

**避ける理由**:
```
他人への批判・詐欺非難が多い
政治的に偏った強い主張ばかり
```

#### 4. テーマが全く関連していない

**避ける理由**:
```
全くフォローアップする予定のないジャンル
```

## 交流候補を見つけるプロセス

### ステップ1: キーワードで検索（毎日15分）

1. 上記の検索キーワードから1つを選ぶ
2. X（Twitter）の検索欄に入力
3. 「最新」タブで投稿を見る
4. 投稿日時の新しいもんから順に確認

**1日の目標**: 3-5人の新規アカウント発見

### ステップ2: プロフィール・投稿を確認（1人5分）

以下をチェック:
- [ ] プロフィール文は何を発信しているか明確か
- [ ] 最近の投稿は試行錯誤・実験を含んでいるか
- [ ] 他人のリプライに返信しているか
- [ ] フォロワー数は適正か（1,000-500,000）
- [ ] 投稿頻度は週2回以上か

### ステップ3: 決定・フォロー＆交流（1人3分）

**ステップA: フォローしない場合**
- 理由をメモ（例：「スパム色強い」「テーマ関連度低い」）
- スキップ

**ステップB: フォローする場合**
- [ ] フォロー
- [ ] 最新の投稿1-2件を読む
- [ ] 返信・引用投稿を検討
  - **返信**: 相手の投稿に直接コメント
  - **引用投稿**: 相手の投稿を引用しながら、自分の実体験を追加

## 返信・引用投稿の例

**詳細ルールは別ドキュメント「docs/reply-worker.md」を参照してください。**

以下は、会話を続ける返信の基本構成です。

### 基本構成：3ステップ

1. **相手の投稿に具体的に触れる** - 単なる褒めではなく、内容を反映
2. **自分の短い感想・経験を添える** - 共感と親近感を作る（2-3行程度）
3. **最後に自然な質問を入れる** - 相手が返しやすい開かれた質問

### 返信例（3パターン）

#### パターンA: 親しみ強め

```
Claudeで予約処理を自動化してる話、めっちゃ気になってました！
自分も今、AIに予約処理を任せ始めてて、
PC閉じたら止まる問題にちょうど困ってます笑

実際、クラウドセッションってどこまで安定して使えてます？
```

**理由**: 砕けた言葉と「笑」で親しみやすさが出て、相手も返しやすくなる

---

#### パターンB: 標準

```
Claudeで予約処理を自動化している話、参考になります。

自分も同じ課題に取り組んでて、今はセッション管理がボトルネックなんですが、
実装時に工夫してることってありますか？
```

**理由**: 相手の投稿を読んでることが明確に伝わり、誠実な質問が返信を促す

---

#### パターンC: 短め

```
予約処理の自動化、気になってました。
同じことやってるんですが、
セッション管理ってどのくらい複雑でした？
```

**理由**: シンプルでも関心が伝わり、相手が答えやすい長さ

---

### 引用投稿例（3パターン）

#### パターンA: 親しみ強め

```
@[アカウント]さんの投稿、その通り。
自分もA/Bテスト試してるんですが、
最初は結果が出なくて何度も心が折れました笑

実装から結果が出るまで、実際どのくらい期間かかりました？
```

**理由**: 失敗や課題を素直に出すことで、親しみと信頼感が生まれる

---

#### パターンB: 標準

```
A/Bテストでの改善事例、参考になります。

自分も同じアプローチで進めてるんですが、
データが安定するまでの判断基準に悩んでまして。

実装時に「これくらいのサンプルサイズなら十分」という
基準ってありますか？
```

**理由**: 相手の知見を尊重しつつ、実務的な質問で対話が深まる

---

#### パターンC: 短め

```
A/Bテスト、同じこと試してます。
効果が出るまでの期間、
実際にはどのくらいの期間見てました？
```

**理由**: シンプルながら、相手のノウハウを引き出せる

## 交流相手の記録方法

毎日、以下をGitHubまたはメモに記録してください：

```
【日付】2026-10-01
【時間】昼12時

【発見したアカウント】
@[handle1] - AIと筋トレを発信している人
- プロフィール：「Claudeを使った業務効率化と筋トレの進捗」
- 最新投稿：「AI導入失敗から学んだこと」
- 判定：✅ フォロー＆返信

【返信内容】
「Claudeでの失敗、共感です。私も最初は〇〇で…」

【結果】
- フォロー：成功
- 返信：投稿完了
- 相手からの反応：（後日更新）

---

【発見したアカウント】
@[handle2] - スパム営業アカウント
- 理由：「無料でXXX」の繰り返し、リプライへの返信なし
- 判定：❌ スキップ
```

## 目標設定

### 毎日の目標

| 項目 | 目標値 |
|-----|-------|
| 新規アカウント発見 | 3-5人 |
| フォロー判定 | そのうち1-2人 |
| 返信・引用投稿 | 1-2件 |
| 時間投資 | 20-30分 |

### 1週間の目標

| 項目 | 目標値 |
|-----|-------|
| 新規アカウント発見 | 20-35人 |
| 新規フォロー | 7-14人 |
| 返信・引用投稿 | 7-14件 |
| フォロー返し | 2-4人（30-50%程度） |

### 重要：大量フォローではなく質重視

- 目標：**毎日1-2人の質の高い相手を発見・フォロー**
- 避けるべき：**毎日50人フォロー、フォロー返し率を狙う**

---

## 参考：フォロー返しが高い層の特徴（参考情報）

実務的には、以下の層がフォロー返しをしやすい傾向：

1. フリーランス（500-50,000フォロワー）
2. AI活用実務者（1,000-100,000フォロワー）
3. マーケター・グロースハッカー（5,000-200,000フォロワー）

しかし、**フォロー返し率は主要KPIではないため、これは参考までに**。質の高い交流を優先してください。

---

## 交流が深まるサイン

以下のような反応が出たら、その人との交流をさらに深めてください：

✅ 相手が自分の投稿にコメント・いいねをしてくれた  
✅ 相手がDMで連絡をくれた  
✅ 相手の複数の投稿に自分もコメントしている  
✅ 相手の投稿をたびたび引用・返信している  

---

**方針**: 量ではなく、本当に関心を持てる相手との継続的な交流を優先します
