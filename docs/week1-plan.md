## 返信・引用投稿テンプレート

### 返信パターン

```
【パターン1：共感型】
「その通りですね。私も [自分の実体験] を通じて同じように感じています。特に [具体例] のところが参考になります。」

【パターン2：質問型】
「なるほど。[相手の内容を要約]、ということですね。
私も [関連する経験] をしているのですが、[具体的な質問] はいかがでしょうか？」

【パターン3：拡張型】
「[相手の内容に同意] は本当にそうですね。
さらに [自分の視点] という側面も重要だと感じています。
[具体例]」
```

### 引用投稿パターン

```
【パターン1：実体験シェア】
「こういう取り組みをしている人を見ると、自分も [実体験] で同じことを感じた。
[具体的な気づき] は本当に大事だと思う。」

【パターン2：手法の応用】
「この手法、[業務名] にも応用できそう。
実は [自分の実務例] をしているんですが、同じ考え方が使えます。」

【パターン3：データ・事例】
「[相手の投稿の要点] ←これ、実データでも確認できます。
[自分の観測] したところ、[具体数値] という傾向が見えました。」
```

## 注意点

1. **毎日必ず実行**: 予約投稿だけでなく、手動での交流を毎日実施
2. **質重視**: 数より、相手のコンテンツを理解した上での返信・引用投稿
3. **実体験を活かす**: テンプレート的な返信は避ける
4. **プロフィール最適化**: 返信する前に、プロフィール文で自分が何をしているか明記
5. **定期確認**: 毎日夜にその日の結果を確認
