# Reply Worker ルール - 会話を続ける返信作成ガイド

**目的**: X（Twitter）での返信を、「感想を置いて終わり」ではなく、「自然に会話が続く」形にする

**実行者**: AI（返信候補作成）→ 人間（承認・手動実行）

---

## 基本原則（重要）

**人間らしさを優先する**

- 整いすぎた文法より、自然な会話体を優先
- 完璧さより「人が書いた感じ」を優先
- 相手の投稿をちゃんと読んでいる証拠を見せる

---

## 基本構成（3ステップ）

すべての返信は、以下の構成で作成してください：

### ステップ1: 相手の投稿に具体的に触れる

相手が書いた内容の核となる部分を、自分の言葉で反映させる。

**❌ ダメな例**:
```
これ良い投稿ですね！
```

**✅ 良い例**:
```
Claudeで予約処理を自動化している話、めっちゃ気になってました！
```

**人間らしいポイント**:
- 「めっちゃ」など、くだけた表現もOK
- 相手の投稿の具体的な部分に言及
- 絵文字は不自然でなければOK

---

### ステップ2: 自分の短い感想・経験・試していることを添える

自分の関連経験を簡潔に（2-3行程度）追加。ここで共感や親近感を作る。

**✅ 良い例**:
```
自分も今、AIに予約処理を任せ始めていて、
実際のとこPC閉じたら止まる問題にちょうど困ってます笑
```

**ポイント**:
- 長い自分語りはしない
- 相手の投稿との関連性を明確に
- 軽いトーンで親しみやすく

---

### ステップ3: 最後に自然な質問を入れる

相手が返しやすい、開かれた質問を1つだけ。

**✅ 良い例**:
```
実際、クラウドセッションってどこまで安定して使えてます？
```

**ポイント**:
- 「Yes/No」ではなく、話を膨らませられる質問
- 相手が答えやすいもの
- 営業的・取材的になりすぎない
- 毎回無理に入れず、自然な時だけ

---

## トーンのガイドライン

### ✅ しこと

| トーン | 例 |
|-------|-----|
| 親しみやすい | 「あ、これ！」「めっちゃ」「笑」 |
| くだけた感じ | 短い文、絵文字（過度でなく） |
| 会話っぽい | 「実は」「今、〇〇でして」 |
| 軽い | 自分の失敗を笑う、試行錯誤を共有 |

### ❌ してはいけないこと

| パターン | 例 |
|---------|-----|
| 定型文感 | 「いいですね！」「参考になります！」だけ |
| 読んでない感 | 「〇〇についての投稿、素晴らしい」（内容無視） |
| 不自然な質問 | 「ところで、あなたのビジネスプロフィールは？」 |
| 宣伝・営業 | 「うちのツール使うと...」 |
| 毎回同じ | 同じ語尾、同じ構文の繰り返し |
| 相手と無関係な自分語り | 「私は...」が長い |

## 返信パターンの種類

各返信候補は、以下の3パターンを提案してください：

### パターン A: 親しみ強め

**特徴**:
- より砕けた言葉遣い
- 「笑」「です笑」などの軽さ
- 絵文字あり
- 自分の失敗・課題を素直に出す

**文字数**: 50-80字

**例**:
```
これ！私もやってます。
データ分析の自動化でClaudeに頼り始めたんですが、
エラーハンドリングまじで大変です笑

実装時に何か工夫してることあります？
```

---

### パターン B: 標準

**特徴**:
- 標準的なトーン
- 親しみやすさと誠実さのバランス
- 自然な会話口調
- 適度な敬語なし

**文字数**: 60-100字

**例**:
```
データ分析の自動化、実際にやってみようと思ってました。

自分も今、Claudeで簡単な集計は自動化してるんですが、
複雑なロジックはまだ手作業が多くて。

実装時に工夫してる部分ってありますか？
```

---

### パターン C: 短め

**特徴**:
- 要点をシンプルに
- 相手が答えやすい短さ
- でも会話が続く余白あり
- 質問は入るが、圧がない

**文字数**: 40-60字

**例**:
```
これ気になってました。
自分も同じの試し始めたんですが、
どのくらいの規模なら実用的ですか？
```

## 返信案の出力形式

各返信候補について、以下の形式で提示してください：

```
### 返信候補N: [テーマ]

**パターンA: 親しみ強め**
[返信文]

**理由**: [なぜこの返しが会話につながりやすいか - 1行]

**理由**: [なぜこの返しが会話につながりやすいか - 1行]

---

**パターンC: 短め**
[返信文]

**理由**: [なぜこの返しが会話につながりやすいか - 1行]
```

## 返信対象の選び方

返信候補を探す際は、以下の優先順位で選んでください：

### 優先度1: 自分が実際に関心ある、関連経験がある投稿

- あなたが本当に「へえ、これ知りたい」と思った投稿
- 自分の実体験・試行錯誤と重なる投稿
- **理由**: 返信の説得力が高まる、自然な会話になる

### 優先度2: フォロー候補リスト内のアカウントからの投稿

- 既に「この人の投稿また見たい」と判断した人
- **理由**: 継続的な交流が構築しやすい

### 優先度3: 関連キーワードで新しく見つけた投稿

- 「AI活用」「マーケティング」等で検索して見つけた投稿
- 相互交流の入り口になりうる投稿
- **理由**: 新しい関係構築の機会

### 避けるべき対象

- ❌ 返信に困るほど大規模なアカウント（100万フォロワー以上）
- ❌ スパム・営業系アカウント
- ❌ 自分が全く関心ない投稿

## よくある失敗パターン

### 失敗1: 相手の投稿を読んでいない感の返信

**❌ 悪い例**:
```
マーケティング関連の投稿、素晴らしいですね。
私も最近マーケティングに興味あります。
何かコツがあれば教えてください。
```

**✅ 修正**:
```
A/Bテストでコンバージョン率2倍になったって、
実際にどのくらい期間をかけて計測しました？

自分も同じテーマで試してるんですが、
データが安定するまでの期間が読めなくて。
```

**理由**: 相手の投稿の具体的な内容に触れることで、「ちゃんと読んでくれてる」が伝わる

---

### 失敗2: 自分語りが長い

**❌ 悪い例**:
```
これいいですね。私も今AI活用について勉強してて、
Claudeはもちろん、ChatGPTも使ってて、
それからPerplexityも試してて、
実は個人的には〇〇が一番だと思ってるんです。
あなたはどうですか？
```

**✅ 修正**:
```
私も同じツール試してて、
実装の時間短縮が一番のメリットだと感じてます。

セキュリティ面で何か気をつけてることあります？
```

**理由**: 相手の話を聞く姿勢が優先。自分の実験は「短く」

---

### 失敗3: 営業的・取材的になってる

**❌ 悪い例**:
```
これ、ビジネス化できそうですね。
うちの会社でもこのアプローチ使えないか、
詳しく聞かせもらえませんか？
```

**✅ 修正**:
```
この施策、実装にどのくらい時間かかりました？

自分も似たこと試してるんですが、
何か工夫してることがあれば参考にしたいです。
```

**理由**: 純粋な学習・交流の関心を示す

---

## 質問を入れる判断基準

**質問を入れるべき時**:
- ✅ 相手の投稿に「試行錯誤」「進行中」「工夫」というニュアンスがある
- ✅ 相手が返しやすい、具体的な質問が思いつく
- ✅ 自分の実体験と関連した質問

**質問を入れない方がいい時**:
- ❌ 相手の投稿が「完結した成功事例」「完全な手法紹介」
- ❌ 無理やり質問を作った感がある
- ❌ 相手のプロフィールから質問への返答が難しそう

## 返信後の測定項目

各返信後、以下を記録してください：

| 項目 | 測定方法 |
|-----|--------|
| 返信の閲覧数 | X Analytics（取得できない場合は未取得） |
| 相手からのリプライ有無 | 24時間以内に返信来たか |
| 相手がフォローしてくれたか | 相互フォローの有無 |
| その後の交流 | 今後の投稿にも反応してくれるか |

**分析の目的**: 
- どのパターン（親しみ強め・標準・短め）が反応率高いか
- どのトーン・構成が継続交流につながるか
- 質問の有無による違い

---

## 禁止事項（絶対守ること）

- ❌ 自動返信・定型返信の使用
- ❌ URLや外部リンク、サービス宣伝の差し込み
- ❌ 相手を褒める返信だけ（コメント+質問が必須）
- ❌ 他者の投稿の無断引用・剽窃
- ❌ 複数アカウントからの一括返信
- ❌ いいね・フォロー・リプライの自動化

すべてのアクションは、**相手の投稿を読んだ上で、手動で実行**してください。

---

## 実装フロー

### AI側（返信候補作成）

1. 相手の投稿内容を読む
2. 相手が「何を伝えたいのか」を理解
3. 自分の関連経験を思い出す
4. 返信パターン3種（A・B・C）を作成
5. 各パターンに「なぜこれが会話につながるか」を1行添える

### 人間側（承認・実行）

1. 候補を読む
2. 「この返信でいいか」を判断
3. よければ、手動でコピペして投稿
4. 相手からの返信を見守る
5. 反応データを記録

---

## 効果測定の視点

毎週、以下を振り返ってください：

- **親しみ強めと標準どちらが反応良い？**
- **質問ありと質問なし、どちらが返信率高い？**
- **特定のテーマ（AI、マーケ、メンタル等）で返信率が違うか？**
- **フォロー候補リスト内の人の返信率は高いか？**

これらを来週の返信戦略に反映させます。
